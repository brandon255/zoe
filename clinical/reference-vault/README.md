- `derived/modeling-guidance.md` contains generalized observations only and may be reviewed for use in the adult-clinical model.

- Apparent age from imagery is not proof of legal age. Inclusion in the modeling workflow requires independent confirmation that every depicted person was an adult and consented to this development use.
